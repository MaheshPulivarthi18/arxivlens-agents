## Goal
Only the chunker knows where each window starts, so it is the one place that can say which page a chunk's text starts on
without copying the windowing (design decision 1). Each chunk gets a `page_start` key when, and only when, the section carries
page breaks and the page can be worked out exactly. Otherwise the key is absent ("unknown"), never a guess. Chunk text and every
other chunk field stay byte-identical, so retrieval quality and embeddings don't change.

## Scope
- `scripts/m0_skeleton.py` `TokenChunker.chunk_sections` only:
  - Keep `tokens = self.tokenizer.encode(sec_text, add_special_tokens=False)` exactly as today (`:202`).
  - When `sec.get("page_breaks")` is a non-empty list and `self.tokenizer.is_fast`: `enc = self.tokenizer(sec_text,
    add_special_tokens=False, return_offsets_mapping=True)`. If `enc["input_ids"] != tokens`, record no page for any chunk of
    this section (no exception). `lead = len(raw) - len(raw.lstrip())` where `raw = sec.get("text", "")`.
  - For each emitted chunk: `char = lead + enc["offset_mapping"][start_i][0]`; `page_start` = page of the last break with offset
    `<= char` (`bisect_right - 1` over the offsets). Set the key only if `char >= page_breaks[0][0]`.
  - `content`, `content_hash`, `chunk_index`, `token_count`, `section_title`, `page_number` and which chunks are emitted are
    unchanged. The chunk text contract (`agents/area-notes/services.md`) is unchanged.
- `tests/test_processor_pages.py` (created by ING-11): append AI-11 tests; reuse the module's fixture builder and oracle helpers.
- Out of scope: `services/processor/`, `services/common/` (backend), `PaperParser` in `m0_skeleton.py`, storing or returning the
  page (ING-11 / ING-11b), `tests/test_m0.py`.

## Acceptance criteria
- [ ] AC1: On ING-11's multi-page fixture PDF, through the production `ProcessorWorker._parse_doc_sections(None, doc)` and
  `TokenChunker(MODEL_NAME)`: every chunk has `page_start`, and it equals the page given by the oracle (the page-specific
  vocabulary of the chunk's first body word, independent of the implementation). At least one chunk has `page_start` greater
  than its section's `page` (test, e.g. `test_chunk_page_start_matches_first_word_page`).
- [ ] AC2: ING-11's `test_chunk_output_identical_to_pre_change` snapshot test passes **unmodified** on this PR (the diff shows no
  change to that test or its literal), and `tests/test_m0.py` passes unmodified. `make eval`: "not run: chunk text identical (AC2)".
- [ ] AC3: Hand-made section dicts (no PDF; real BGE tokenizer), table-driven:
  (a) breaks at known offsets inside one section → each chunk's `page_start` is the page at its first token's character;
  (b) an overlap window that starts before a break and ends after it → the earlier page;
  (c) a window starting exactly at a break offset → the new page;
  (d) leading whitespace in `text` (non-zero `lead`) → still correct;
  (e) no `page_breaks` key, and `page_breaks: []` → no `page_start` key on any chunk;
  (f) a stand-in tokenizer with `is_fast = False`, and one whose `__call__` ids differ from `encode` → no `page_start` key, chunks
      otherwise identical to the no-breaks output;
  (g) for every case, the chunk dicts minus `page_start` equal the output for the same sections without `page_breaks`.
- [ ] AC5 (from ING-11 QA finding 1): a second PDF fixture, built by a **new** module-level builder appended to
  `tests/test_processor_pages.py` (ING-11's `build_fixture_doc` and its snapshot stay unmodified, AC2), covers two layouts ING-11's
  fixture doesn't: (a) body text before the first heading (the `Abstract` bucket, `worker.py:118`), so the `Abstract` section is
  emitted with `page_breaks` and its chunks get the oracle page; (b) a heading as the last line of page N with its body starting on
  page N+1 → that section's `page_breaks[0] == (0, N+1)` and its first chunk's `page_start == N+1` while `page == N`. On every chunk
  of both fixtures, `page_start >= 1` when present (a 0 would hit the `CHECK` and fail the processor's transaction).
- [ ] AC4: The PR is < 400 changed lines (estimate ~85, design condition 7); the ownership check passes for `agent/ai/AI-11`.
