## Goal
`filterRelevantHits` (`rag.go:785-799` @ `11c4696`) treats a hit as an auxiliary section with
`strings.Contains(lowerSec, "table")`, so ordinary section titles such as "Notable results", "Stable training" or
"Suitable baselines" need rerank >= 0.70 instead of >= 0.45 and are silently dropped from `/v1/ask` evidence. QA-6's intent
is table *sections* ("Table 3: Hardware", "Tables"). Make the table match whole-word, keep the appendix/supplementary
behaviour, and pin both with tests.

Second (comment-only): the `parseSynthesis` doc comment (`rag.go:664`) says that when every claim is dropped
"synthesize refuses with all_citations_unsupported", but the code falls back to the quoted answer
(`finalizeClaims` nil → `fallback("claims_unsupported")`). Correct the comment to what the code does.
