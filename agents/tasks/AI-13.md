## Goal
OPS-H6e taught `save_chunk_embeddings` to accept `(chunk_id, model, vec, content_hash)` and to write a vector only while
the chunk still has that hash (otherwise skip, no FK error). Until the worker passes the hash, that path is unused and
the embedder can still (1) save a vector of text the processor replaced mid-run, or (2) fail the whole message with an
FK error when the processor's tail delete removed a chunk mid-run. This task makes the worker use it.

## Scope
- Files expected to change:
  - `services/embedder/worker.py`: `process_message` builds 4-tuples `(c["chunk_id"], self.model_name, vec_list,
    c["content_hash"])` (`get_chunks_for_embedding` already selects `pc.content_hash`), uses the **returned** count, and
    logs written vs skipped (e.g. `Saved 30 embeddings for <id> (2 skipped: chunk text changed or removed since read)`).
    Update the `List[Tuple[...]]` annotation. The paper is still marked `embedded` and committed in the same transaction.
  - `tests/test_verify.py` (already in `PY_ML_TESTS`, so it runs in CI `make test-py-ml`; no `Makefile` change): unit test
    with a fake embedder and monkeypatched `get_chunks_for_embedding` / `save_chunk_embeddings` / `update_paper_status` /
    `get_db_connection` asserting the 4-tuples passed (including each chunk's hash) and the log line for a skipped count.
- Out of scope: `services/common/db.py` (backend; OPS-H6e/OPS-H6f), the processor, schema.

## Acceptance criteria
- [ ] AC1: every tuple the worker passes to `save_chunk_embeddings` is a 4-tuple whose 4th element is that chunk's
  `content_hash` from `get_chunks_for_embedding`.
- [ ] AC2: the log reports the number actually written (the function's return value) and the skipped count when > 0;
  it no longer reports `len(embeddings_to_save)` as saved.
- [ ] AC3: a skipped vector doesn't fail the message: status still becomes `embedded`, one commit, no rollback.
- [ ] AC4: unit test(s) in `tests/test_verify.py` cover AC1-AC3; mutants killed: hash dropped (3-tuple), wrong hash
  (e.g. another chunk's), skipped count ignored in the log.
- [ ] AC5: CI `Python M0 unit tests`, `Go`, `Agent ownership check` and `Full stack` green (M2/M3 pipeline suites embed
  real papers through this path). Ruff (E,F,W, 130) clean on added lines.
- [ ] AC6: `make eval` not required (write path only; vectors for unchanged chunks are identical), say "not run: <reason>".
- [ ] Docs: none in the app repo.
