## FE-0: Classic research theme: fonts, tokens, dark mode, theme toggle

**Agent:** frontend-engineer · **Spec:** [agents/tasks/FE-0.md](https://github.com/MaheshPulivarthi18/arxivlens-agents/blob/main/agents/tasks/FE-0.md) · **Design:** [docs/design/FE-0.md](https://github.com/MaheshPulivarthi18/arxivlens-agents/blob/main/docs/design/FE-0.md) (approved with conditions) · **PRD ref:** Product PRD UI-1, UI-2, §7 principles 1 and 3 · **Jira:** story `labels = "task-FE-0"` (epic KAN-5)

This is the design's "FE-0a" part. The six other primitives (tooltip, popover, collapsible, scroll-area, separator, sonner) are FE-0b and are **not** in this PR.

### What changed
- `src/index.css`: light (paper/ink) `:root` and dark (warm near-black) `.dark` token sets, all shadcn names kept, plus new `--supported`, `--unsupported`, `--unchecked` (+ `-foreground`). Ink-blue accent (`--primary` = links, primary action, `--ring`). `--input` is ≥ 3:1 and a comment next to it states the rule: **every control outline uses `border-input`, never `border-border`**. Body is now `font-sans`. Scrollbar re-tinted via tokens. `--radius` 0.65rem → 0.375rem.
- `tailwind.config.js`: `font-sans` = Inter Variable stack, `font-serif` = Source Serif 4 Variable stack, `mono` kept (system fallback). `supported`/`unsupported`/`unchecked` colours. `@tailwindcss/typography` registered, with a token-mapped `DEFAULT` prose theme (`maxWidth: 70ch`, follows `.dark` without `prose-invert`). `clinical` and `title` are kept but marked deprecated. `darkMode: ["class"]` kept.
- `src/main.jsx`: imports `@fontsource-variable/inter`, `@fontsource-variable/source-serif-4` and `…/source-serif-4/wght-italic.css`.
- `index.html`: Google Fonts `<link>`s removed (no request to fonts.googleapis/gstatic). Adds `<meta name="color-scheme">` and an inline pre-paint script in `<head>` that sets `.dark` before React mounts.
- New `src/lib/theme.js` (plain ESM: `getStoredTheme`, `setStoredTheme`, `resolveTheme`, `systemPrefersDark`, `applyTheme`, `watchSystemTheme`) and `src/components/ThemeToggle.jsx` (Light / Dark / System radio menu, persisted in `localStorage["arxivlens-theme"]`, live OS-change follow in System, cross-tab sync).
- New `src/components/ui/dropdown-menu.jsx`: shadcn-style Radix wrapper (Content, Label, Item, RadioItem, Separator forwardRef'd; `cn()`; tokens only; `data-[highlighted]` focus; `font-sans` content).
- `ui/button.jsx`: only the `default` variant changes, to `bg-primary text-primary-foreground` (no existing caller used it).
- `Navbar.jsx`: on tokens. The brand is now a keyboard-reachable `<button>`, tabs get `aria-current="page"`, and the brand, tabs, Index Paper, Infrastructure and theme button all have a visible 2px focus ring. Gradient, emerald and glow are removed, the outlined button uses `border-input`, and `<ThemeToggle/>` is mounted.
- App `README.md`: one sentence on the theme toggle under "Run the UI".

No dependency changes (all packages were already in the lockfile from #64/#67). No change to `package.json`, `package-lock.json`, `vite.config.js` or any file in #68.

### For Mahesh: three reversible choices (how to veto)
1. **First visit is dark until FE-3**, even for OS-light users (`DEFAULT_THEME = "dark"` in `src/lib/theme.js` and in the `index.html` pre-paint script). Light mode would put the ask flow's hard-coded text at ~1.16:1 until FE-3 moves it to tokens, and FE-3 has an AC to flip the default to `"system"`.
2. **The "Clinical Research AI" badge is removed** (above).
3. **The accent is ink blue, not arXiv red.** Red stays reserved for *unsupported* and *destructive*, so "click here" never looks like "this claim failed".

To overrule any of them, leave a review comment on this PR (for example "keep the badge", "default to system now" or "use arXiv red"). It goes back to frontend-engineer as a rework item. Each change is a constant or a few lines.
